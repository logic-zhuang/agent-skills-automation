## 演示步骤（约 3 分钟）

1. 将 `personal-profile.md` 上传到 OpenWorker **知识库**  
2. （可选）问一句：「李俊杰的学号和高考总分是多少？」→ 证明库已生效  
3. 上传空白《本科新生入学登记表》`.docx`  
4. 加载 **Word文档操作**（或 WPS）技能，说：「用知识库里的档案填写这张入学登记表」  
5. 打开生成的 **draft**，在审阅中看红色修订 → 强调「先草稿、人确认、再定稿」

## 话术要点

- 用户**只维护档案**，不写坐标、不插书签  
- 同一份档案可填多张不同表  
- 照片、复杂多选 □ 等可说明为「半自动 + 人工确认」

空白表请自备学校原件；技能 examples 里若有 `form.docx` 副本也可临时用。
