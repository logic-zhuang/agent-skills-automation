## 扫全 vs 填满

| 问题 | 看什么 |
|------|--------|
| 表扫全了吗？ | `coverage.unresolved_labels` / `unbound_empties` |
| 能自动填吗？ | `matched`（扫到 + 档案有值） |
| 档案多出来？ | `unmatched_kb`（正常） |

## 空格原因（对照截图）

| 空项 | 识别到了？ | 为何空 |
|------|------------|--------|
| 信教开始时间 | 是 | 档案无值 → **故意不填** |
| 家长姓名/关系/单位/住址/邮编 | 是（表头↓空行） | 档案无家属字段 → **故意不填** |
| 家属「联系电话」格 | 是 | 会拿档案「联系电话」填入（学生电话；若要家长电话需档案区分） |
| 语文/数学/总分 | 是（表头↓） | 档案无分数 → **故意不填** |
| 外语（语种） | 是 | 档案有「英语」；须填**下方**（表头行），已用 header-row 优先下 |
| 考生/招生类别 □ | 是（unknown） | **故意不填**，等确认 |
| 乘车区间「至」后 | 否 | 句中续写，未建模 |
| 照片 | 否 | 非文本 |
| 第二行家属空行 | 部分 unbound | 多行家属表尚未按「两行」写 |

右空且下空时：列表头行 / 右空缝后还有标签 → **优先下**；否则默认右。
