## 空着的格子：原因说明

| 空项 | 原因 |
|------|------|
| 出生日期 年/月/日、加入年月、入学年月 | **没扫成可填 slot**：右侧格是「年　月　日」模板字，不是空白，当前只认空格/占位符 |
| 家长姓名等一整块 | **没扫到**：表头行 + 多行空网格，还没做「多行家属表」kind |
| 考生类别 / 招生类别 □ | **没扫到**：多选 □ 挤在一格里，和「是□否□」不同 |
| 乘车区间「至」后面 | **没扫到**：左边已有「克拉玛依 至」，不是空单元格 |
| 语文 / 数学 / 总分 | **没扫到**：分数格布局特殊（标签与空格不在「右邻一格」模式） |
| 照片 | 非文本，不填 |
| 信教开始时间 | **扫到了**，档案里无值 → unmatched（故意可空） |

已填的 16 项 = 扫到了 + 共用档案里有值。
